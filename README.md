# Sistema Bancário em Java

Projeto desenvolvido para praticar conceitos fundamentais da linguagem Java e Programação Orientada a Objetos.

## Funcionalidades

- Cadastro de contas
- Associação entre cliente e conta
- Busca de contas pelo número
- Listagem de contas
- Depósito
- Saque
- Validação de conta inexistente
- Validação de saldo insuficiente

## Conceitos praticados

- Classes e objetos
- Encapsulamento
- Construtores
- Métodos
- Getters e setters
- Associação entre classes
- List
- ArrayList
- Estruturas de repetição
- Validações

## Tecnologias

- Java
- IntelliJ IDEA
- Git
- GitHub

## Objetivo

Projeto criado durante meus estudos de Java com o objetivo de fortalecer minha base em POO e desenvolver lógica de programação através de um projeto prático.
